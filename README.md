 Responsive Product Pricing Cards

A modern and responsive SaaS pricing page built using HTML, CSS, and JavaScript. This project features interactive monthly and yearly billing options, stylish pricing cards, hover animations, and promotional badges.

✨ Features

- 📱 Responsive design for mobile, tablet, and desktop
- 🔄 Interactive monthly/yearly billing toggle
- 💰 Dynamic price updates using JavaScript
- 🎨 Modern UI with smooth hover effects and transitions
- ⭐ Popular and Best Value pricing badges
- 🖱️ Interactive buttons and toggle switch
- ♿ Accessible toggle control with ARIA attributes
- 📊 Three pricing plans: Starter, Professional, and Business

🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- CSS Grid and Flexbox
- DOM Manipulation
- Event Listeners
- CSS Transitions and Transforms

🚀 Getting Started

1. Clone or download this repository.
2. Open the project folder.
3. Open "index.html" in your web browser.
4. Switch between Monthly and Yearly billing.
5. Hover over the pricing cards to explore the animations.

🎨 Design Decision

I chose a clean, modern design with a purple accent color, rounded cards, subtle shadows, and smooth hover animations to create a professional SaaS pricing experience. The monthly/yearly toggle allows users to compare billing options easily, while responsive layouts provide a consistent experience across different screen sizes.
